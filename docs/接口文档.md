# 智仓 · 接口文档

- Base URL：`http://127.0.0.1:8000/api`
- 认证：除登录与健康检查外，均需请求头 `Authorization: Bearer <token>`
- 编码：`application/json; charset=utf-8`
- 时间格式：`YYYY-MM-DD HH:MM:SS`（东八区）

## 统一响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {}
}
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 400 | 参数错误 |
| 401 | 未登录 / token 失效 |
| 403 | 无权限；`code=1002` 表示需先修改初始密码 |
| 404 | 资源不存在 |
| 409 | 业务冲突（重复、库存不足、删除保护等） |
| 500 | 服务异常 |

分页响应统一为：

```json
{ "items": [], "total": 0, "page": 1, "page_size": 10 }
```

## 1. 认证

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/auth/login` | 公开 | 登录 |
| POST | `/auth/logout` | 登录 | 登出（无状态，前端清 token） |
| GET | `/auth/me` | 登录 | 当前用户、权限码、菜单树 |
| PUT | `/auth/password` | 登录 | 修改自己的密码 |

登录请求：

```json
{ "username": "admin", "password": "Admin@123456" }
```

登录响应 `data`：

```json
{
  "token": "eyJ...",
  "user": {
    "id": 1, "username": "admin", "real_name": "系统管理员",
    "role": { "id": 1, "code": "admin", "name": "系统管理员" },
    "must_change_password": true
  },
  "menus": [
    { "id": 1, "name": "工作台", "path": "/dashboard", "icon": "Odometer",
      "permission": "dashboard:view", "children": [] }
  ],
  "permissions": ["dashboard:view", "product:view"]
}
```

修改密码请求：

```json
{ "old_password": "Admin@123456", "new_password": "Admin@2026" }
```

返回新的 `token`、`user`、`menus`、`permissions`（旧 token 立即失效）。

## 3. 商品

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/products` | `product:view` | 分页列表 |
| GET | `/products/{id}` | `product:view` | 详情 |
| POST | `/products` | `product:create` | 新增 |
| PUT | `/products/{id}` | `product:update` | 编辑（不含库存） |
| DELETE | `/products/{id}` | `product:delete` | 删除（有流水时拒绝） |

列表查询参数：`keyword`、`category`、`status`（1/0）、`low_stock`（1）、`page`、`page_size`（≤100）。

新增请求：

```json
{
  "code": "", "name": "青提茉莉冷萃原液", "category": "咖啡原料",
  "spec": "500ml/瓶", "unit": "瓶", "safety_stock": 5,
  "cost_price": 18.5, "sale_price": 32, "initial_stock": 0,
  "status": true, "remark": ""
}
```

> `initial_stock > 0` 需要 `stock:in` 权限，并自动生成「期初入库」流水。
> 库存只能通过出入库接口变更，编辑商品不会修改库存。

## 4. 库存

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/stock/in` | `stock:in` | 入库 |
| POST | `/stock/out` | `stock:out` | 出库（库存不足返回 409） |
| GET | `/stock/records` | `stock:view` | 流水分页 |
| GET | `/stock/records/recent` | `stock:view` | 最近流水 |
| GET | `/stock/today` | `stock:view` | 今日出入库汇总 |

出入库请求：

```json
{ "product_id": 1, "quantity": 10, "remark": "供应商到货" }
```

成功响应：

```json
{
  "product_id": 1, "product_name": "青提茉莉冷萃原液",
  "stock": 46, "quantity": 10, "type": "IN",
  "order_no": "IN2026110100012", "created_at": "2026-11-01 10:20:31"
}
```

流水查询参数：`type`（IN/OUT）、`keyword`、`product_id`、`date_from`、`date_to`、`page`、`page_size`。

## 5. 用户

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/users` | `user:view` | 分页列表 |
| POST | `/users` | `user:create` | 新增 |
| PUT | `/users/{id}` | `user:update` | 编辑姓名/手机/角色 |
| DELETE | `/users/{id}` | `user:delete` | 删除（自己/内置/最后管理员拒绝） |
| PATCH | `/users/{id}/status` | `user:update` | 启用/停用 |
| POST | `/users/{id}/reset-password` | `user:reset` | 重置密码 |
| GET | `/users/{id}/menus` | `user:grant` | 读取用户菜单配置 |
| PUT | `/users/{id}/menus` | `user:grant` | 保存用户菜单配置 |

新增用户：

```json
{
  "username": "zhangsan", "password": "Zhang@123",
  "real_name": "张三", "phone": "13800000000",
  "role_id": 2, "status": true, "must_change_password": true
}
```

菜单配置：

```json
{ "mode": "custom", "menu_ids": [1, 2, 3, 4, 5, 6] }
```

`mode=inherit` 跟随角色；`mode=custom` 以 `menu_ids` 为准（仍受权限约束）。

## 6. 角色与权限

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/roles` | `role:view` | 角色列表（含权限与菜单） |
| GET | `/roles/permissions` | `role:view` | 权限清单（按模块） |
| GET | `/roles/{id}` | `role:view` | 角色详情 |
| POST | `/roles` | `role:manage` | 新建角色 |
| PUT | `/roles/{id}` | `role:manage` | 修改名称/说明 |
| DELETE | `/roles/{id}` | `role:manage` | 删除（内置/有用户时拒绝） |
| PUT | `/roles/{id}/permissions` | `role:manage` | 保存功能权限 |
| PUT | `/roles/{id}/menus` | `role:manage` | 保存菜单权限 |

保存功能权限：

```json
{ "permissions": ["dashboard:view", "product:view", "stock:in", "stock:out"] }
```

保存菜单权限：

```json
{ "menu_ids": [1, 2, 3, 4, 5, 6] }
```

> 菜单会自动补齐其页面权限（如勾选「用户管理」自动加入 `user:view`）。
> 超级管理员角色（code=`admin`）不可修改。

权限码清单：

| 模块 | 权限码 |
| --- | --- |
| 工作台 | `dashboard:view` |
| 商品 | `product:view` `product:create` `product:update` `product:delete` |
| 库存 | `stock:in` `stock:out` `stock:view` |
| 系统 | `user:view` `user:create` `user:update` `user:delete` `user:reset` `user:grant` `role:view` `role:manage` `menu:view` `menu:manage` |

## 7. 菜单

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/menus` | `menu:view` | 菜单树 + 角色列表 |
| GET | `/menus/registry` | `menu:view` | 已注册页面 / 可用页面 |
| POST | `/menus` | `menu:manage` | 新增菜单（页面 / 分组） |
| PUT | `/menus/{id}` | `menu:manage` | 修改名称/图标/排序/显隐/上级 |
| DELETE | `/menus/{id}` | `menu:manage` | 删除（内置/有子级时拒绝） |
| PUT | `/menus/{id}/roles` | `menu:manage` | 设置可见角色 |

新增页面菜单：

```json
{ "type": "page", "path": "/products", "name": "商品管理",
  "icon": "Goods", "sort": 2, "visible": true, "parent_id": null }
```

新增分组：

```json
{ "type": "group", "name": "报表中心", "icon": "Folder", "sort": 8 }
```

设置可见角色：

```json
{ "role_ids": [1, 2] }
```

> 超级管理员始终可见全部菜单，配置对其不生效。
